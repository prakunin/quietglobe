# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.x | Yes |

## Reporting a vulnerability

Please do not report security issues in public GitHub issues.

Use GitHub Security Advisories:

https://github.com/prakunin/quietglobe/security/advisories/new

Or contact the maintainer through the GitHub profile:

https://github.com/prakunin

Please include:

- A description of the issue.
- Steps to reproduce.
- macOS version and hardware.
- Potential impact.

We will acknowledge the report as soon as possible and coordinate a fix and disclosure.
